# mini-world
我的微世界

一个 pnpm monorepo+vue3+vite 的项目

参考文章1：https://juejin.cn/post/7357546247848198182?searchId=20260114105418062410EFA242D27B2770
参考文章2：https://juejin.cn/post/7212538330829996092?searchId=20260114105418062410EFA242D27B2770

我的node环境版本为：v22.19.0

在根目录下(monorepo-world)创建项目命令：
pnpm create vite main-project --template vue

在根目录下(monorepo-world)执行
pnpm -F main-project add common

安装依赖 pnpm i 都在根目录下进行安装
